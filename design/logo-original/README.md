# Original logo — preserved

The complete original logo component and browser icon are saved here unchanged.
The original landscape drawing also remains available as `LandscapeMark` in the current component.

To switch back, change `logoStyle` to `"landscape"` in `src/components/brand.tsx`, copy this folder's `icon.svg` over `src/app/icon.svg`, then rebuild the site.

The new grass Q is original SVG artwork. Its editable generator is `scripts/create-grass-q.mjs`; its standalone transparent SVG is `public/brand/grass-q.svg`. The existing Fraunces and Manrope lettering is retained.
